# Дневник

Школьный дневник советского образца — шестидневка, разворот на неделю, отметки красной ручкой — но рабочий: он не про ностальгию, а про то, чтобы неделя была спланирована с вечера и проверена в субботу.

Один файл `index.html`. Ни сборки, ни зависимостей, ни сервера, ни аккаунта. Открывается двойным щелчком, работает офлайн, всё хранится в браузере.

## Что внутри

**Разворот недели.** Слева понедельник, вторник, среда; справа четверг, пятница, суббота — ровно как в оригинале. Воскресенья нет: выходной не планируют.

**Отметка щелчком.** По клетке «отм.»: 5 → 4 → 3 → 2 → н → пусто. Шкала оговорена в правилах и она не про старание:

- **5** — сделано и ушло наружу
- **4** — сделано, но лежит у тебя
- **3** — начато
- **2** — не тронуто

Черновик в папке — никогда не пятёрка. Отметка ставится в тот же день, а не «в конце недели разберусь».

**Графа «Поведение».** В старом дневнике она была про дисциплину на уроке. Здесь — про привычки, ради которых неделя и затевалась: клетка щёлкается пусто → выполнено → сорвалось, считаются дни подряд. По правилам дневника эта графа весит больше отметок: неделя с четырьмя тройками и шестью чистыми днями лучше недели с пятёрками и срывом.

**Итоги.** Средний балл, сколько заданий закрыто, сколько двоек, сколько чистых дней, разбивка по предметам.

**Новая неделя.** Закрывает текущую и переносит невыполненное следующей — хвосты не теряются и видно, что таскается из недели в неделю.

**Печать.** Печатает все разделы подряд. Формат — альбомный A4, тогда разворот встаёт как в книге.

**Файл.** «Сохранить в файл» / «Загрузить из файла» — обычный JSON. Хранение только у тебя: ни сервера, ни аналитики, ни трекеров.

Всё редактируется прямо в клетке — предметы, задания, дни, даты. Правь как в тетради.

## Своя неделя

По умолчанию открывается демо-неделя. Чтобы дневник открывался со своим расписанием, создай `personal/my-week.js`:

```js
window.MY_WEEK = {
  weekNo: "I",
  dates: "31 августа — 5 сентября 2026",
  bells: [
    ["1 урок","09:00 — 09:45"],
    ["большая перемена","10:40 — 11:10 · улица, 30 минут"]
  ],
  habits: [
    {name:"Без сигарет", note:"главная графа недели"}
  ],
  days: [
    {name:"Понедельник", date:"31 августа", note:"Первый день.", lessons:[
      {subj:"Физкультура", task:"Прогулка сорок минут.", tag:"день 1"}
    ]}
  ]
};
```

Папка `personal/` лежит в `.gitignore` — свои дела в открытый доступ не уедут.

Дневник читает этот файл один раз, при первом запуске. Дальше он живёт в браузере: правки в клетках останутся, даже если потом менять `my-week.js`. Чтобы перечитать файл заново — кнопка «Очистить всё».

## Про предметы

Названия школьные, содержание — взрослое. Смысл в том, что разнородные дела перестают быть одной серой кучей «дел» и раскладываются по предметам, у каждого своя отметка:

| Предмет | Про что на самом деле |
|---|---|
| Арифметика | деньги: расходы, ставки, отчёты, цифры |
| Русский язык | тексты: описания, письма, ответы |
| Правоведение | документы и сроки |
| Информатика | инструменты, скрипты, техника |
| Труд | производство и отгрузка |
| Черчение | всё визуальное |
| История | разбор сделанного, дневник, итоги |
| Физкультура | тело, сон, режим, привычки |

Свои — просто впиши вместо этих.

## Большая перемена

В расписании звонков между вторым и третьим уроком стоит тридцать минут улицы. Это не оформительская деталь: перерыв поставлен ровно туда, где у бросающего курить стоял перекур, и он должен быть выходом из дома, а не сменой вкладки.

## Как устроено

Ванильный HTML, CSS и JavaScript, один файл. Шрифты — PT Sans Narrow, PT Serif и Caveat с Google Fonts; без сети подставятся системные, дневник останется рабочим. Светлая и тёмная темы: тёмная — не инверсия, а бумага под настольной лампой.
